HOW TO USE NEW CLEANUP:
A. Combine -> Remove Existing Image Text -> Use Downloaded Slides or Choose Images.
B. Approve detected OCR captions or draw a Rectangle around an existing caption.
C. Select Brush Select / Restore to add GREEN SELECTION over text pixels.
D. Select Eraser (Mask) to REMOVE green selection covering products/labels.
E. Use Undo/Redo and brush size as needed. Default Clean Fill, feather 0px.
F. Click Preview Text Removal, compare original with cleaned preview.
G. Save Clean Copy + Add to Combine only after confirming product details.

NOTE: Eraser is a SELECTION eraser, not a destructive pixel eraser. With brush
or eraser edits, use Clean Fill (Photoshop Content-Aware does not honor those
precise holes). Original downloaded image files are never overwritten.
