INSTALLATION
1. Back up the entire current BrandForge project.
2. Extract the ZIP into a temporary folder.
3. Copy and MERGE the contents of the extracted folder into your original project
   root next to package.json; replace individual files, don't replace the entire
   src directory if Windows asks to move/delete directories.
4. Run VERIFY_BRANDFORGE_ROOT.cmd, then launch BrandForge as usual.
5. For developer verification: npm run validate.

NOTE: This is complete SOURCE, not a compiled EXE. On Windows, an EXE must be rebuilt.
      The Python test script is optional QA only, not required to run BrandForge.
