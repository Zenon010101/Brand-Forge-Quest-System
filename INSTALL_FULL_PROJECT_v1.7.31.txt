BrandForge v1.7.31 — FULL SOURCE PROJECT

1. Close BrandForge and make a full backup of the original project directory.
2. Extract this ZIP to a new folder; package.json must sit beside src and test.
3. Either use the extracted folder as the new source project, or merge every extracted file into your original project root.
4. Run VERIFY_BRANDFORGE_ROOT.cmd; confirm src\main\main.js exists.
5. Start BrandForge with your normal Electron/NPM launcher. (When using a compiled portable EXE, rebuild it from this source.)
